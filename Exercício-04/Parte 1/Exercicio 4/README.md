# Exercício 4 - TechStore (Parte 1: Planejamento e Estrutura Inicial)

Loja virtual fictícia multipáginas, desenvolvida como parte do Exercício 4 da
trilha de desenvolvimento frontend, dentro do repositório `frontend`, na
pasta `Exercicio 4`.

## Objetivo desta etapa

Criar a base do projeto com a estrutura de arquivos correta antes de
qualquer estilização, garantindo que todo o CSS será externo (arquivo
`css/style.css`), sem uso de `style="..."` inline ou tags `<style>`.

## Estrutura de pastas

```
frontend/
└── Exercicio 4/
    ├── css/
    │   └── style.css
    ├── img/
    ├── index.html
    ├── produtos.html
    ├── contato.html
    └── README.md
```

## Páginas criadas nesta etapa

- `index.html` — página de boas-vindas (ainda sem estilização).
- `produtos.html` — página reservada para a galeria de produtos.
- `contato.html` — página reservada para o formulário de contato.

Todas as páginas já possuem cabeçalho básico com o nome da loja e menu de
navegação (Início, Produtos, Contato), rodapé simples, e estão ligadas ao
mesmo arquivo `css/style.css` externo.
