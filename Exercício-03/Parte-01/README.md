# Exercício 3 — PokéAcademy Landing Page

Landing page temática sobre o universo Pokémon desenvolvida com **HTML5** e **CSS3** externo.

## Estrutura do Projeto
- `index.html`: Estrutura com tema Pokémon (Hero, Sobre, Recursos e Rodapé).
- `css/style.css`: Estilização externa sem CSS inline ou tag `<style>`.
