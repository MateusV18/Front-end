Portfólio — Loja Virtual Verde Vida

Apresentação

Este portfólio apresenta o projeto Verde Vida, desenvolvido pela equipe de desenvolvimento front-end como exercício prático de criação de uma loja virtual responsiva do zero, sem uso de frameworks ou JavaScript.

O projeto e o tema escolhido

A Verde Vida é uma loja fictícia de plantas e jardinagem, cujo objetivo é oferecer plantas selecionadas, vasos artesanais, substratos e acessórios de iluminação solar para quem deseja criar um cantinho verde em casa. O tema foi escolhido por permitir uma identidade visual rica em tons de verde e âmbar, que transmitem frescor, natureza e bem-estar.

O projeto evoluiu em 5 partes: da estrutura base com variáveis CSS, passando pela home e pelo portfólio inicial, pela galeria com páginas individuais de produto, pelo menu responsivo e media queries, até a finalização com interações visuais e acessibilidade.

Tecnologias utilizadas

  • HTML5 — estrutura semântica com header, main, section, article, nav e footer.
  • CSS3 externo — todo o estilo centralizado no arquivo css/style.css, sem CSS inline ou interno.

Decisões de responsividade

  • Mobile First: os estilos base atendem primeiro aos dispositivos móveis, com aprimoramentos progressivos para telas maiores.
  • Media Queries: breakpoints em 768px (tablets) e 1024px (desktops) para ajustar layouts e tipografia.
  • CSS Grid: galeria de produtos em 1 coluna no mobile, 2 no tablet e 3 no desktop.
  • Flexbox: alinhamentos do header, hero, página de detalhe e rodapé.
  • Menu responsivo sem JavaScript: abertura do menu hambúrguer controlada por input checkbox e o seletor :checked.
